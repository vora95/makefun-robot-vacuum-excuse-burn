One robot-vacuum excuse for a missed spot (134 characters), written by a deterministic program (`main.ts`, Node stdlib only, no network):

> I didn't miss that spot. My map says it isn't there, and I trust my map more than I trust your eyes — so the spot is your problem now.

`main.ts` validates the entry (1–140 chars, single line, no trailing newline), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, and verifies the file on disk is byte-identical (sha256 logged).
